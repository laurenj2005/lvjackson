Home Styles

HTML * CSS * JavaScript

A three-page website about interior design and architectural styles, built for a University of Georgia web course. It grew out of an earlier project. I added interactive elements and reworked the design to make the site more engaging.The idea came from touring open houses with my mom during COVID, which turned into a love of home design.

Travel Around the World

HTML * CSS * Bootstrap

A multi-panel travel website built with Bootstrap, featuring travel-inspired content, an interactive map, and customized webpage layouts. I explored Bootstrap's responsive structure, integrated map content, and adapted pre-built templates to create distinct designs. This project strengthened my front-end development skills and taught me how to customize existing components to fit my design vision.
